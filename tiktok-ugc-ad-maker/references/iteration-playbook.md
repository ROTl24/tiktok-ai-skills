# Iteration Playbook

Use this reference after the video is published: when the user asks 复盘 / 迭代 / 怎么优化 / 数据不好怎么办, or as the final step of section `13. 下一步操作`.

The thresholds below are starting heuristics, not guarantees. They vary by category, market, and account size; judge trends across 3-5 videos, not a single post.

## Metrics to Read (first 48-72 hours)

| 指标 | 说明 | 主要反映 |
| --- | --- | --- |
| 3秒完播率 / Hook rate | 看满3秒的观众占比 | Hook 强度（前2秒） |
| 平均播放时长 / 完播率 | 观众中途流失的位置 | 节奏与信息密度 |
| 点赞 / 收藏 / 转发 | 共鸣与实用价值 | 选题与卖点 |
| 评论内容 | 观众的问题、异议、需求 | 下一条视频的素材 |
| 主页/链接点击率 (CTR) | 看完后行动的比例 | CTA 与购买理由 |
| 商品卡点击 / GPM / 转化率（挂车时） | 从点击到成交 | 价格、落地页、信任 |

## Decision Tree

- 3秒完播率低（多数品类低于约 50-60% 就值得警惕）: hook 问题。用 Hook Variant Mode 只换镜头1和开头口播，一轮测 2-3 个变体，视频身体部分不动。
- 3秒还行但 5-10 秒大量流失: 节奏问题。用 Incremental Update Mode 做分镜级修改：把演示/关键卖点时刻前移、压缩 Problem 段、删掉过场帧。
- 播放时长健康但 CTR 低: CTA 或购买理由问题。属于下游修改：加强 CTA 口播与字幕、把最强卖点在结尾重复一次、确认挂车入口或 bio 链接清晰。
- CTR 正常但转化差: 落地页与视频不一致。回到 section `5` 的落地页一致检查，先修页面（价格、主图、承诺），不要急着改视频。
- 评论区反复出现同一个问题或质疑: 把它做成下一条视频的 hook，或用回复视频承接流量。

## Test Cadence

- 每轮 3-5 条视频，只改一个变量；第一轮永远先测 hook。
- 大致判断：明显跑赢账号均值的素材加投或复制角度；持平的换 hook 再试一轮；连续两轮都差的回到 section `3`/`4` 换卖点角度或广告结构。
- 保留一张简单记录表：hook、结构、核心卖点、关键指标、结论。它是下一次 section `2` 默认假设的依据。

## How to Ask the Skill

- 只换开头: `给我3条hook变体` → Hook Variant Mode。
- 改某个镜头/结构/时长: `把第3镜改成...` → Incremental Update Mode（分镜级，会联动更新口播/B-roll/Seedance 并重出核对表）。
- 只改字幕、音效、CTA 文案: 下游修改，只更新对应模块。
- 换新品: 重新走完整流程，不复用旧产品的 hook 和话术。
